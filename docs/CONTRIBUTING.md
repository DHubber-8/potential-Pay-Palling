# Contributing

1. Propose a task in `docs/TASKS.md` with status `Proposed`.
2. After agreement, set it to `Approved`, assign an owner, and record approval.
3. Work on a branch named `<task-id>-short-name`, and update the file header when starting.
4. Open a pull request using the template; a different team member reviews it.
5. Agree on S1 and S2 before dependent tasks start.
6. Stay within the task's files where possible and mention cross-area changes in the pull request.
